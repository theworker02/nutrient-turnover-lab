# Changelog

## 0.1.0 — 2026-09-25

Initial release of **Nutrient Turnover Lab**, an educational Streamlit exhibit on fruit-fly nutrient turnover and comparative life-history speed.

- Seven-page multipage app: Overview, Fruit Fly Nutrients, Why They Multiply, Comparative Species, Simulators, Quiz, Sources
- Fourteen-species teaching set with literature-anchored ranges (`labkit/species_data.py`)
- Interactive models: nutrient–yeast–larva coupling, logistic races, stage-structured boom, Kleiber allometry
- Custom moss/amber UI, Plotly charts, quiz gallery, methods/citations page
- Demo screenshots under `demo/`
